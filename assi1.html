Least five different text formathing tags

1st text format

Bold TextThis tag defines bold text without adding any special semantic importance.

2nd text format

Important text: This tag defines text with strong importance; browsers typically display it as bold.

3rd text format

Italic text: This tag defines a part of text in an alternate voice or mood, such as a technical term or a phrase from another language; it is typically displayed in italics.

4rt text format

Emphasized text: This tag defines emphasized text, which is typically displayed in italics and conveys semantic meaning (e.g., screen readers will put verbal stress on the content).

5th text format

Marked text: This tag defines text that should be marked or highlighted, usually with a yellow background color.
